## Selected work

### Evaluation against customer test data

A US regional bank needed to score models on its own test data, a feature stranded in a legacy UI. I moved the supervised workflow into the new product in about five months; customers used it in production.

<a href="/work#test-set-evaluation" class="cta">
  See the case study
</a>

### Customer-defined evaluation metrics

Customers could define their own metrics only through the API. I took it to a full UI workflow: packages of up to 50 metrics, per-file upload validation, and the API changes behind it. All three phases were built behind a feature flag; one UI fix was still in review when I left DataRobot.

<a href="/work#custom-metrics" class="cta">

</a>
